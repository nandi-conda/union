# union

[KDE Union](https://invent.kde.org/plasma/union) and the KDE Frameworks 6 it
needs, packaged for conda against conda-forge's Qt (`qt6-main 6.11.2`, the Qt
conda-forge's PySide6 uses), so `org.kde.union` loads into a pixi PySide6 app.

Published to [prefix.dev/nandi-testing](https://prefix.dev/channels/nandi-testing):

```bash
pixi add --channel https://repo.prefix.dev/nandi-testing kde-union pyside6
```

## Layout

- `recipe.yaml`: Union itself (`kde-union`).
- `recipes/`: its chain (`kf6-*`, `cxx-rust-cssparser`), built in `recipes/ORDER`.
  The `kf6-*` recipes are generated by `scripts/gen_recipes.py` (`pixi run gen`).
- `ci/pre-package.sh`: builds the chain into `output/`, which the Union build uses
  as a local channel. CI runs it through the shared [nandi-conda/ci](https://github.com/nandi-conda/ci) workflow.

Build everything locally with `pixi run build`.

## Example

[`examples/pyside6-demo`](examples/pyside6-demo) is a small PySide6 app using the
`org.kde.union` style from this channel (`pixi run demo`).
